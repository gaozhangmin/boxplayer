# 来源与扫描适配

本地与网盘文件列表共用文件类型图标。已有缩略图优先显示，缺失或加载失败时，按原始文件名、来源类型与文件大小显示视频、音频、图片、文档、压缩包等图标。

刮削剧集详情的「显示缺失季」和「显示缺失集」使用各自的本地偏好，默认开启。仅在有播出覆盖数据时生成缺失占位，保留已有剧集和播放记录。阿里云盘媒体路径读取当前文件及其祖先目录，目录不可读时显示文件名。

本地文件操作日志在 Windows 使用卷序列号和文件索引核对同一个文件或目录。无法读出身份、目标被替换或存在重解析点时停止恢复。Electron 导出包的本地来源根路径须是当前平台可解释的绝对路径。

路径按本仓库根目录解释。修改前核对当前源码和调用者；本文不宣称已完成运行验收。

本文涉及的 Tauri 迁移源码随 `codex/dev-tauri` 分支版本管理。原生验收使用 `tauri-app/`，不能用旧 Electron 根工程代替；源码已提交不代表目标平台已验收。

## 运行路径与状态

来源选择 → 收藏/扫描调度 → 适配与持久化 → 新 UI 展示。检查调用的究竟是旧代码移植、适配层还是 Rust 命令；迁移清单完成不代表真实账号验收。

添加本地目录使用原生选择 ID 保存。来源保存成功后再执行扫描。扫描失败提示来源已添加，文件浏览保留可用状态。点击本地文件触发的播放错误单独提示。

## 既有产品规则

## Home Category Context Menus

- Categories and independently placeable subcategories, including series, playlists, movie/TV child categories, genre, rating, score, and release-date values, use the same placement context-menu state machine.
- An unplaced item shows “Add to Home” and “Add to Favorites”; both actions prompt for a user-defined display name.
- After either add action succeeds, or when the item is initially visible on Home, the menu immediately switches to “Remove from Home” and “Rename Favorite.” The menu must not allow simultaneous Home and Favorites placement.
- “Remove from Home” clears whichever placement contains the item. Renaming a favorite changes only its Favorites card title and does not rename the Home or sidebar title.
- Exception: media server categories expose only Favorites actions (plus play / loop / shuffle); their Home shelf is managed in the Add to Home sheet and is independent of the Favorites card.

## 文件来源浏览与收藏规则

来源窗口保存本地文件夹后，原生层把已保存的来源 ID 交给主窗口。主窗口等当前扫描空闲并确认来源仍在，再调用同一目录扫描入口。扫描出错时，提示已保存的目录与扫描失败原因。

- 网盘、网络共享、媒体服务器沿用本地文件夹的来源浏览与收藏交互；取消网盘、网络共享的文件夹收藏（子文件夹或整盘“所有文件”）会移除收藏卡片，并清除从该文件夹（整盘即整个网盘）刮削到媒体库的媒体，但保留来源，也不删除网盘或共享里的文件。媒体库里可添加到收藏夹和主屏幕的类别（如电影下的按类型、按评价或某个具体类别）取消收藏只移除快捷卡片，不影响已收录媒体。删除来源会清理该来源的全部关联媒体。
- 媒体服务器使用服务端元数据，不为服务器目录启用本地刮削。
- 媒体服务器浏览页不展示本地媒体库扫描提示。已存储共享中打开媒体服务器时直接列出实际库或条目，不添加“所有文件夹”收藏占位。
- Tauri 媒体服务器根页展示服务器返回的媒体库卡片，音乐库卡片打开该库的曲目列表。页面加载失败时在内容区顶部显示重试横幅，同一服务器账号和线路已有的根页卡片继续显示。分页及独立区块使用局部错误提示。
- Tauri 媒体服务器列表请求成功且无可显示条目时，按媒体库、分类或搜索场景显示无操作按钮的空状态。
- Tauri 的侧边栏服务器与「文件」页服务器卡片使用同一入口，打开服务器媒体库根页。切换服务器浏览路径时，内容区从顶部显示。
- Tauri 主屏幕加载本地目录或服务器栏位期间，右上角刷新按钮显示加载环并暂时禁用，已有栏位继续显示。服务器浏览页的加载环放在内容区中央。
- 主屏幕服务器栏位共用 12 秒读取上限，各横栏独立左右滚动。后台更新同一服务器账号的快照时，保留已经打开的分类和详情。媒体服务器和刮削媒体库详情共用 `MediaDetailPage.vue` 与 `MediaDetailInfo.vue`，由同一页面渲染固定顶部栏、封面与播放区、滚动内容和媒体信息卡片，并遵循应用的亮暗主题。各入口通过自身适配读写媒体版本、观看状态与集合。
- 侧栏和文件首页打开服务器时进入同一媒体库根页。主屏幕或收藏直达服务器子页时，返回先进入该服务器媒体库根页。重复搜索替换当前搜索页，保留进入搜索前的页面。
- 主屏幕与服务器页共享服务器条目的路由判断，剧集海报进入详情，媒体库目录保留分类路由。服务器横栏有内容或重试提示时，主屏幕不显示无来源空页。从刮削详情进入标签分类后，返回可恢复原详情。文件来源从侧栏或文件卡进入时，目录根页返回文件首页。
- 主屏幕的服务器读取失败显示在对应栏目及重试入口。发现媒体库失败且没有失败栏目承接时，显示以服务器命名的重试栏目。
- 主屏幕「系列」和「播放列表」只显示启用的 TMDB 合集、自定义系列及已创建的播放列表。没有分组时省略横栏，分组子页按成员读取。
- 媒体服务器列表接近底部时自动追加下一页。请求失败保留已加载的条目和游标，重试仍加载同一页。
- 桌面主屏幕滚动位置和媒体库的来源筛选、排序在同一窗口会话内保留。文件目录返回沿用已加载的父目录列表，远程目录一并恢复分页游标。
- 服务器播放列表和合集索引仅展示对应类型的服务器条目。服务端返回普通视频时，不把这些条目计作分组，也不自动遍历全库寻找分组。
- 主屏幕首行合并本地媒体库与启用的媒体服务器的继续观看条目，并用横向海报展示进度和已观看／总时长。无续播条目时首行合并展示最近添加。
- 远端视频列表行右侧提供可操作的下载入口；解析与下载均使用文件所属账号，并保留所需请求头。
- 媒体服务器分类的收藏夹卡片与主页横排相互独立、可同时存在：分类卡片菜单只提供 播放 / 循环播放 / 随机播放 / 添加到收藏夹（已收藏时为 从收藏夹移除 / 重命名收藏夹），不提供添加到主屏幕，主页横排在“添加到主页”弹窗中管理；具体电视剧、季等内容条目只允许收藏卡片。本地媒体库分类仍按主屏/收藏夹互斥规则。
- 网盘、网络共享没有收藏时，文件 tab 显示网盘卡片，进入后为文件浏览（显示所有类型）。有任一收藏后文件 tab 隐藏该网盘卡片、只显示收藏卡片，取消最后一个收藏后恢复；已存储共享始终列出所有网盘。Electron 没有已存储共享页，网盘卡片始终显示。
- 整盘收藏有两个入口且效果相同：网盘卡片菜单的“添加到收藏夹”和已存储共享中网盘根目录“所有文件夹”占位的五角星。卡片名为“所有文件”，list 视图显示所属网盘名；整盘收藏与子文件夹收藏可同时存在。
- 从收藏卡片（主屏幕收藏夹或文件 tab）进入时为海报样式，只显示文件夹和视频，仍按目录逐级进入。文件 tab 卡片、主屏幕收藏夹卡片和已存储共享五角星都可取消收藏。
- 媒体服务器不走刮削，文件 tab 内默认海报浏览；添加后固定显示在主屏幕收藏夹，不能取消收藏。
- “添加到收藏夹”与“添加到主页”是两种行为。主屏幕编辑弹窗标题为“添加到主页”；只添加到收藏夹的项目不出现在其“显示项目”中。
- 浏览样式按入口区分。新增文件来源 → 已存储共享（网盘、网络共享、媒体服务器）是纯文件浏览：紧凑列表行（小的橙色图标、名称、“日期 - 大小”），文件夹行右侧五角星，视频行右侧下载入口，空目录显示“空文件夹 / 这儿什么都没有。”。文件 tab 和主屏幕进入的文件夹是媒体库海报样式，列表（海报底板 + 标题 + 简介）和网格两种布局可切换：已收藏刮削的文件夹显示刮削海报、只显示视频；文件 tab 未收藏的网盘、共享卡片没有刮削，开启“显示视频预览”时用视频缩略图代替海报，否则显示图标，非视频文件也显示，列表副标题为“日期 - 大小”。两种海报浏览里的子文件夹都可添加到收藏夹。
- 点击视频直接播放；手机上点击图片、PDF 直接预览，TV 可预览图片。
- 在已收藏并刮削过的文件夹（含整盘收藏）里再收藏子文件夹，不重新刮削，只新增收藏卡片。
- 取消这类仍被其他收藏覆盖的子文件夹收藏（整盘“所有文件”或上级文件夹收藏还在）时，只移除卡片，媒体库里的媒体保留，因为它们属于覆盖它的那个收藏。
- 用户添加的本地文件夹从文件 tab 和主屏幕进入时，视频优先显示刮削海报，刮削不到元数据时才回退到本地视频缩略图。
- 媒体服务器的收藏卡片（主屏幕收藏夹与文件 tab 一致）按类型使用不同菜单：分类文件夹为 播放 / 循环播放 / 随机播放 / 从收藏夹中移除 / 重命名收藏夹 / 在主屏幕隐藏（已隐藏时为在主屏幕显示）/ 选择封面；电视剧等内容文件夹为 播放 / 循环播放 / 随机播放 / 收藏（切换服务器端收藏）/ 选择封面。“在主屏幕隐藏”只影响主屏幕，文件 tab 仍显示该卡片。
- 主屏幕收藏夹卡片和文件 tab 对应卡片使用一致的菜单与收藏状态；按实际能力覆盖 Apple、Android（含 TV）和 Electron，TV 不新增本地文件夹入口。

## 文件来源与目录排序（2026-11-19）

文件来源卡片、侧栏和主屏幕使用同一排序结果；名称、修改时间、添加时间、观看时间支持升降序，排序选项左侧显示方向箭头，重复点击当前项切换方向，无独立升降序行；另保留拖拽自定义顺序。显式排序不受旧拖拽顺序覆盖，拖拽重新进入自定义模式。目录列表同样支持四项排序（保留大小排序），文件夹始终置顶；来源与目录网格使用自适应伸缩列，按实际内容区宽度铺满，避免非全屏右侧留下固定列宽余量；视频、图片、文档、字幕及全部筛选放在右上角“更多 → 文件类型”二级菜单并保存到文件偏好，筛选不移除文件夹导航，也不改写底层目录/分页数据。

修改时间读取本地/来源实际文件时间，目录添加时间优先采用媒体库收录时间或来源创建字段。来源新增、重命名和新服务器收藏记录相应时间；已有来源缺失的历史时间不以当前时间伪造。观看时间由有效播放进度记录，未收录文件亦可记入文件与来源；已知收藏目录关联同步记录。未知时间在两种方向均置末尾，同值按名称稳定排列。偏好兼容旧手动顺序并保留该顺序供切回；新增书签、重命名及观看字段原子保存，避免跨窗看到半次变更。

本次重复点击规则统一适用于 Tauri 的文件来源/目录、网盘独立窗口、媒体库（含收藏卡片）、媒体服务器、书库及书摘/笔记、全局搜索。字段菜单仅当前生效项左侧显示方向箭头，其他项保留对齐空位，不再提供独立升降序行；搜索提供商的默认相关度属于非方向字段，保持原默认语义。音乐界面当前没有用户可选的排序按钮，不新增无数据契约的排序入口。

## 主屏幕生命周期与收藏夹布局（2026-11-19）

Tauri 主窗口以最多两个 KeepAlive 实例分别保留主屏幕和其他媒体库浏览页，跨文件/音乐/图书页面返回不重新挂载主屏幕或重新请求服务器栏目；停用时撤下工具栏传送内容并关闭上下文菜单，激活时恢复标题、详情状态和纵向滚动。服务器来源/设置变更及手动刷新仍走原有更新链路。catalog.ensureLoaded 合并首次加载并复用成功快照，失败后允许重试；显式 load 与保存不被缓存阻断。收藏夹网格使用可伸缩列铺满可用宽度，不限制为 220px。

详情页仅在条目身份变化时重置季/集/版本选择；观看、收藏保存成功后更新同一条目状态，不清空详情、关联栏目或滚动位置，失败保留旧状态。目录由自身约束高度并负责纵向滚动，切换目录重置此容器；目录加载失败在内容区显示并重试失败目标，不发全局 toast，也不伪装为空目录。仅凭 5113 不能确认请求操作或提供商原因，本轮不改写业务失败为成功，不承诺解除提供商限制。

## 详情操作与来源连接（2026-11-19）

Tauri 媒体服务器详情播放下方依次为观看、下载、评分、收藏、播放列表，右上角为播放列表和更多。观看成功更新同一集条目及其未观看角标，不重载详情；父级观看状态同步已加载的相关子项。电视剧下载统一弹出单集、未观看剧集、全部剧集选择，批量结果按真实服务器观看状态过滤。评分沿用 Trakt 星级评分链路，收藏仍调用媒体服务器 API，期间显示独立反馈弹窗。

非服务器详情依次为观看、下载（本地当前文件隐藏）、评分、Trakt 待看、系列、播放列表，右上角为 Trakt 待看和更多。详情待看要求 Trakt 已连接且启用同步，并有准确 TMDB 标识；同步成功后才保存本地归属，失败保留原状态。系列、播放列表复用已有集合选择器。加载反馈中的“关闭”仅隐藏提示，不伪装成取消远端已发出的写入；连接测试才提供实际取消。
