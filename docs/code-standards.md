# 代码、文档与交付标准

- 先读 [子系统索引](subsystems/README.md) 的所属页面，核对源码入口、调用者和数据写入。一个修改只解决其目标，保留其他会话的代码和暂存状态。
- 错误、超时、解析失败或未知状态不能写成空列表、确认无匹配或成功保存；保留既有账号、设置与可恢复数据。
- URL、账号与必需请求头一起传递；过期请求不得覆盖新会话。协议变化核对旧客户端、失败处理、状态和持久化兼容。
- 原有执行限制见 [开发约束](agent-development.md)，优先于通用验证建议。文档整理不自动授权业务测试、构建、安装、发布或生产写入。
- 已获授权的验证应覆盖用户行为与失败边界；fixtures 不能冒充真实服务通过。报告注明提交、执行命令、证据和未执行范围。
- 契约变化与实现同步更新所属页面；内部重构不改变契约时说明行为保持。评审追踪上游调用和下游影响，不只看 diff。
- AI 每次犯错，修正后、任务结束前必须记录日期、事实、原因、修正、预防与证据。优先写工作区根 LESSONS.md；根缺失或不可写时写本仓库 LESSONS.md，恢复后汇总。重复犯错仍追加本次记录。
