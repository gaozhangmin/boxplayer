# 2026-11-19：Tauri 详情操作与文件源编辑

范围为用户指定的 Tauri 新桌面端，包含媒体服务器与非服务器详情、独立来源窗口及旧来源管理入口；不扩展到其他客户端，不发布正式版本。

## 已实现

- 媒体服务器：播放下方五个操作按观看、下载、评分、收藏、播放列表排列。剧集未观看角标直接响应保存后的状态；父级观看更新已加载的相关子项。下载使用单集/未观看/全部选择弹窗，收藏保存期间显示反馈，右上角保留播放列表与完整菜单。
- 非服务器：本地当前文件隐藏下载；远端电视剧复用同一下载范围弹窗；待看经 Trakt 同步后写入本地归属，详情入口要求已连接、启用同步及准确 TMDB 身份。评分使用已有 Trakt 星级弹窗；系列和播放列表使用已有集合面板，补齐底部播放列表按钮。菜单图标/标题按统一列对齐，点击后关闭菜单。
- 文件源：列表铅笔进入对应 accountId 的编辑页，密码不回显。右上角移除共享经过确认，底部保存/网络测试/端点管理等宽；网络测试和端点管理复用已有页面。
- 添加网络来源：连接中显示反馈，失败保留表单并弹出确认提示；WebDAV 在保存前读取草稿根路径，HTTP 失败或无效 WebDAV 响应均不保存，取消后不继续保存。媒体服务器/SMB/NFS/FTP 沿用原生先鉴权/列目录再写账号的链路。AList 令牌方式先测试根目录。

加载反馈的“关闭”只隐藏远端写入的提示；只有连接测试的“取消”调用实际 auth/HTTP 取消，不假装撤销已发出的远端写入。旧来源与媒体库其他入口保留原有离线个人状态规则，详情待看单独要求 Trakt。
