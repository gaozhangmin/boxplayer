# 2026-11-19：Tauri 排序与文件类型菜单

范围是新 Tauri 客户端，维护分支 codex/dev-tauri；不改 Electron、Apple、Android，不发布客户端。

文件首页与目录支持名称、修改时间、添加时间、观看时间，目录保留大小排序。显式排序覆盖旧拖拽顺序，未知时间始终置末；播放时间由有效播放进度记录，缺失历史时间不伪造。来源卡片、侧栏和主屏幕共用来源顺序。网格采用可伸缩列以填满非全屏内容区。

目录筛选收纳到右上角“更多 → 文件类型”二级菜单，支持全部、视频、图片、文档、字幕，始终保留文件夹。应用已有排序控件统一重复点击当前字段切换方向：文件、独立网盘窗口、媒体库及收藏、媒体服务器、书库/笔记/书摘、全局搜索。字段左侧显示方向箭头，不再提供独立升降序行；提供商默认相关度保持非方向语义。
