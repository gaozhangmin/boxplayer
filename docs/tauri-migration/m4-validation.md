# M4 验收记录

日期：2026-11-07。工作区：`boxplayer-tauri` / `feat/tauri-migration`。本阶段以实施计划M4的开发及本机合成验收为完成范围；用户明确真实账号检查后置。结论：该范围完成，停在M5前；不宣称真实账号、真实用户旧库、全部平台或发布验收通过。

## 扫描、关联和取消

`catalog.ts` 在目录请求返回后、逐项处理、元数据返回、来源刷新及排队写入前检查扫描代次。完整扫描成功后才清理该根内缺失文件；分页/读取失败不清空旧库。相同文件身份不重复，重叠根有独立归属；增量不重复刮削成功且大小不变的文件，保留手工元数据、观看、收藏、个人评分、继续观看和集合引用。

`scanScheduler.ts` 以来源/根为检查点，串行调度并支持失败退避；可选15分钟、1小时、每天，默认关闭，主窗口运行及重新获得焦点时检查。不是后台系统服务，不承诺应用退出后唤醒。取消已发送的原生保存事务无法撤销，但过期代次不会继续提交新的工作。

原生来源清理使用同一SQLite事务删除本地来源、媒体和集合引用；空来源也推进媒体库revision，使旧扫描写入冲突。合成触发器制造保存失败，证明来源删除和媒体清理一并回滚。

## 元数据与原版页面

TV封装响应正确解包，按实际季集取得名称、简介、剧照、时长、演职员和预期集数，不生成演示集。详情映射从各文件版本聚合元数据；保存手工编辑把缓存协议地址还原为公开原图URL。原版主页、媒体库、详情、播放列表、个人评分和多版本组件的已有行为回归保留。

Trakt同步精确匹配电影或TMDB+季/集；同集多版本全部更新，新本地进度优先，范围过滤和最新远端记录生效，不把暂停进度推断成已看完。原版Trakt资料页已含观看统计，使用原生响应校验；未新增无来源的观看次数。

## 原生图片缓存

`artwork_cache.rs` 注册公开TMDB `mscache://` 图片通道，磁盘缓存跨重启，7天有效期、单图8MiB、每缓存目录128MiB上限，拒绝任意外部URL、凭据查询串及非允许栅格图片。过期/损坏图片失效，超预算按旧文件清理。

服务器图片通过 `server_artwork` 账号绑定网关取回，原生缓存键包含账号、服务地址、用户及完整图片版本路径。WebView只接收数据/Blob；退出账号清理缓存，请求期间退出不会重新写回该账号缓存。账号A/B隔离和退出清理回归通过，真实服务器图片等待账号验收。

## 旧版格式副本与v2导入

`catalog_migration.rs` 使用版本、来源版本、表清单计数和SHA-256；JS导出器与Rust共享递归排序JSON和数字规范，跨语言副本实际导入通过。表包括本地来源、位置、媒体、播放列表、自定义系列和允许的显示/布局偏好。

`electron-video-export.mjs` 读取调用方明确选择的 IndexedDB 副本，仅 readonly `imedia_item`，不读取token表，也不打包任意localStorage。以显式来源映射投影原电影/季集/版本、收藏、已看和个人评分，过滤嵌套凭据字段及签名链接。开发依赖fake-indexeddb用于原表结构的合成副本回归，不进入应用运行产物。

原生导入把本地来源/文件身份转换为Tauri canonical路径身份，同时转换集合引用、偏好身份及秒数续播键。临时真实目录回归比较导入ID、原生列表ID和播放器续播记录，完全一致，防止重扫增殖或续播失联。已有目标媒体/位置优先；来源或媒体身份冲突拒绝，集合引用缺失、格式、表计数和校验错误均拒绝。

导入前快照保存在独立数据库的 `catalog_imports.backup`，媒体/来源/位置/导入标记同一事务提交。模拟SQL错误后所有写入回滚；重试成功；重复导入不增殖。偏好由返回结果补缺，不覆盖目标已有偏好；它是WebView兼容存储，不声称与SQLite构成跨存储原子事务。M2 v1导入仍兼容。

设置页提供“检查迁移文件”、导出、导入及数量报告。检查只验证manifest，不导入。原生检查按钮已实屏打开系统选择器；未选择/读取用户真实旧库，未把合成条目灌入用户应用。
