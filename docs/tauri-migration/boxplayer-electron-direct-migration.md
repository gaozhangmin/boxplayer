## 运行方式

原版 boxplayer 已是持久任务工作流，不是旧方案所述的前端唤醒定时器。为保留其状态机，TypeScript 引擎在编译后的独立原生进程中运行；Rust 负责启动、回收、白名单 DTO 通信和后续原生账号边界。Bun 内置 SQLite 适配原仓库的同步事务 API，避免 Electron ABI 相关 better-sqlite3 addon。

构建机需要 Bun，最终应用用户无需安装 Node/Bun。当前 macOS arm64 独立进程约 85 MiB，使 debug app 从 122.36 MiB 增加到 207.90 MiB；此体积代价保留在记录中，不能沿用旧包体积。Windows/Linux及跨架构需要在对应目标构建机验证，构建脚本拒绝把宿主可执行文件用于其他目标。

- 独立进程按需启动，数据固定在 Tauri 应用数据目录的私有 `boxplayer/boxplayer.db`；标准输入输出通信限制帧长、编号和请求时间，错误后销毁进程，防止迟到响应串号；应用退出回收子进程。
- 启动时恢复中断运行任务为排队状态。不会自动执行这些任务；当前 `status` 明确返回 `storageReady=true, workerReady=false`。
- 原生命令及前端 DTO 客户端已接通。WebView 不能提交数据库路径、任意 SQL、凭据或任意提供商操作。
