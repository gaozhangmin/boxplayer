# 阿里云盘两阶段登录修复

2026-11-10：Tauri 原入口直接执行 OpenAPI 扫码并发布账号，缺失 Electron 原有的网页登录阶段。

现改为原生网页登录 → OpenAPI 二次扫码 → 同一用户标识校验 → 保存单一组合账号。第一阶段凭据仅暂存原生内存，不发布账号；第二张二维码过期可单独刷新。关闭窗口取消待处理登录。网页与 OpenAPI 请求分别使用对应凭据，保留已有设备签名和受保护凭据存储。

验证：前端聚焦测试 37 项通过；原生测试 234 项通过，13 项既有外部环境测试忽略；类型检查和 Electron 来源校验通过。已完成签名开发包构建，并通过原生菜单退出旧版、确认退出后重新启动新版，主屏幕正常显示。Electron main 未修改。

真实账号两次扫码尚待用户验证；此次不将自动化回归等同于真实扫码验收。
