# 2026-11-19：Tauri 主屏幕、详情和文件浏览

本轮仅修改 Tauri 新桌面端，分支 codex/dev-tauri。保留其他平台及并行迁移工作，不发布客户端。

## 行为

- 收藏夹网格取消 220px 列宽上限，伸缩列铺满内容区，保留最后一行正常空位。
- 主屏幕和其他本地媒体库浏览各保留一个 KeepAlive 实例。跨文件、音乐、图书页面返回不重新挂载主屏幕。停用时移除工具栏，激活时恢复标题、详情状态及滚动位置。catalog.ensureLoaded 合并首次加载且复用已成功读取的数据；显式刷新、catalog:changed、扫描和持久化仍更新数据。
- 本地详情以条目身份而非对象引用重置季、集、版本选择。服务器详情的收藏/观看保存成功后更新条目状态，失败保留旧状态，不再清空详情后重载。
- 文件目录具备独立的有界纵向滚动容器；切换目录重置该容器。全局目录错误 toast 已移除；真实目录失败在内容区呈现并重试失败目标，成功后清除提示，不伪装为空文件夹。
