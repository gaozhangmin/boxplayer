# BoxPlayer v5.0.39

## 简体中文
- 统一资源搜索、元数据与内置 AI 的默认 API 地址。
- Pro 账户未设置默认模型时自动使用内置 AI，保留明确选择的自定义模型。
- 优化 PDF 工具栏、适合宽度显示和中文 AI 问答侧栏，补充独立预览窗口的网盘账号初始化。
- 调整设置页账户信息、Pro 标识及更新提示布局。

## 繁體中文
- 統一資源搜尋、中繼資料與內建 AI 的預設 API 位址。
- Pro 帳戶未設定預設模型時自動使用內建 AI，保留明確選擇的自訂模型。
- 改善 PDF 工具列、符合寬度顯示及中文 AI 問答側欄，補上獨立預覽視窗的雲端硬碟帳戶初始化。
- 調整設定頁帳戶資訊、Pro 標示及更新提示版面。

## English
- Unify the default API origin for resource search, metadata and built-in AI.
- Use built-in AI by default for Pro accounts without a saved default model, while preserving explicitly selected custom providers.
- Improve the PDF toolbar, fit-to-width layout and Chinese document chat sidebar; initialize cloud accounts in standalone preview windows.
- Refine account details, Pro badges and update notices in Settings.

## Validation / 验证范围
- TypeScript checks and 13 focused AI configuration tests passed before release preparation.
- PDF rendering and sidebar layout were checked in the existing macOS dev app.
- Real PDF AI answering remains unverified: document extraction returned HTTP 400 during the latest check.
- Five failures in the broader bookAI suite were reproduced on the unchanged baseline.
- Platform packaging and playback acceptance are handled by the release workflow; a draft is not a public release.
