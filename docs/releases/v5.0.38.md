# BoxPlayer v5.0.38

本次更新集中完善账户会员体系、通用设置、系列与多版本管理，并改进 AI 刮削、音乐播放和文档查看体验。

## 账户与会员

- 设置中心新增会员头部与统一的 BoxPlayer PRO 标识；侧边栏、账户页和设置页使用同一套徽标，并按全平台、Android、Apple 权益显示对应身份。
- 新增扫码登录：设置页直接展示设备登录二维码，授权完成后自动恢复应用会话。
- 账户区域改为可展开面板，保留会员状态同步与退出登录；新增关注、帮助中心和问题反馈入口，反馈邮件会自动附带版本与系统信息。
- Pro 权益目录与后端授权范围对齐；未知产品仍保留 Pro 身份，但不会错误标记为更窄的平台权益。

## 通用设置与隐私

- 新增「通用」设置页：外观（跟随系统 / 浅色 / 深色）、排序方式、隐藏剧透、显示 Logo、外部评分、最近播放、观看状态、每日精选、自动连播、自动下载字幕、显示文件名、文件管理、海报片名和匿名错误报告。
- Logo、评分与每日精选支持「全部 / 仅电视剧 / 仅电影 / 关闭」显示范围。
- 关闭文件管理后隐藏删除操作；关闭海报片名后仅显示海报。
- 匿名错误报告可以关闭；上报内容移除请求 URL 与服务端错误文本，仅保留必要的分类字段。

## 系列与多版本

- 新增「系列与版本」设置：电影 / 电视剧列表显示系列、使用 TMDB 系列、自定义系列、打开系列进入详情、电影多版本合并、默认版本和播放版本。
- 多版本支持自动、优先较大文件、优先较小文件三种顺序；关闭合并后，同一影片的每个文件会作为独立海报展示。
- 系列可以显示在电影或电视剧列表顶部；自定义系列遵循开关，并支持点击后直接进入成员详情。
- 详情页和媒体库播放统一使用版本优先级；手动选择版本后按所选文件播放。
- 重新刮削时只移除已经迁移的旧文件，保留原条目中未被新结果覆盖的文件和集合成员。

## AI 刮削与元数据

- 切换到媒体刮削 v2 契约：批次内使用稳定 ID 与索引校验，拒绝缺失、重复或错位结果；支持可重试错误和最多 3 次重试，每批 10 个文件，客户端超时 60 秒，置信度阈值提升至 0.70。
- 支持一次返回多集和特别篇（第 0 季）；剧集结果可以批量合并，不再依赖服务端返回的 TMDB ID。
- 改进文件名年份识别：支持空格或点分隔的年份，同时保留《1917》《2012》《流浪地球 2》等数字片名。
- TMDB 请求超时覆盖响应体读取阶段，并补充 408 重试，避免响应体卡住时长时间等待。
- 音频扩展名优先识别为音频文件，修正网盘将音频标记为视频时的图标与分类。

## 播放与媒体库

- 音乐播放改用内嵌 MPV 音频模式，支持媒体来源请求头、均衡器、声像与变速效果，并在播放结束后自动切换下一首；进度、音量、静音和跳转状态保持同步。
- 视频播放新增自动下载字幕：仅在内嵌字幕、同目录字幕和已下载字幕均不存在时尝试，失败不会中断播放。
- 通用设置中的自动连播与播放器内设置双向同步。
- 修复 PDF 连续翻页或缩放时的渲染竞态，限制位图内存并串行渲染；图片查看器关闭过渡动画，改善手势响应。
- 修复网盘根目录递归下载时子目录为空的问题，并调整详情页剧集标题布局。
- 媒体服务器与本地媒体库的评分、Logo、观看状态和每日精选遵循通用显示设置。

## 文件来源与界面改进

- 统一主页与文件页空白状态，排序按钮显示当前排序方式与方向。
- 修正内嵌 MPV 多请求头参数的编码，避免认证请求头被拆分。

- 修复阿里云盘备份盘等目录从右键菜单收藏时未弹出命名框、未启动刮削、收藏卡片未显示的问题；整盘收藏与星标入口使用统一流程。

- 新增文件来源统一采用左右分栏：先填写来源名称，再连接网盘；授权内容在右侧显示，不再额外弹出旧网盘登录窗口。
- WebDAV 与 AList 归入网络共享；Emby、Jellyfin、Plex 和本地文件夹使用统一的内嵌添加表单。
- 文件来源支持自定义名称，完善网盘与共享的文件浏览、文件夹收藏和媒体服务器收藏入口。
- 统一浅色、深色主题下的弹窗、下拉框及浮层背景，调整设置与会员界面；阿里云盘备份盘、资源盘显示名称更清晰。
- 统一应用更新通知，展示下载状态与更新内容。

## 下载与说明

安装包由本次发布流水线构建并附于 Release。macOS、Windows 和 Linux 请按设备架构选择；Apple 平台及 Android / Android TV 的下载入口见 [官网](https://xbyvideohub.com/)。

本版本先以 draft release 形式准备，由维护者检查后手动公开。

# BoxPlayer v5.0.38 (English)

This release focuses on membership, general preferences, series and multi-version management, plus improvements to AI scraping, music playback, and document viewing.

## Account and membership

- Added a membership header and a unified BoxPlayer PRO badge across the sidebar, account page, and settings, with separate identities for all-platform, Android, and Apple entitlements.
- Added device QR sign-in from Settings. The app polls the device authorization and restores the session automatically.
- The account area is now an expandable panel with membership sync and sign-out. Added Follow, Help Center, and Report a Bug links; bug reports include the app version and system details.
- The Pro entitlement catalog now matches backend scopes. Unknown products remain Pro without being mislabeled as a narrower platform entitlement.

## General settings and privacy

- Added a General settings page for appearance (system / light / dark), sort order, spoiler hiding, logos, external ratings, recently played, watch indicators, daily picks, auto-play next, automatic subtitles, file names, file management, poster titles, and anonymous error reports.
- Logo, ratings, and daily picks support All / TV only / Movies only / Off display scopes.
- Disabling file management hides delete actions; disabling poster titles shows artwork only.
- Anonymous error reports can be disabled. Reported data no longer includes request URLs or server error text, only the required classification fields.

## Series and versions

- Added a Series & Versions settings page for showing collections in movie or TV lists, using TMDB collections, custom collections, opening collections directly in details, merging movie versions, and choosing default and playback versions.
- Multiple versions can be ordered automatically, by larger file first, or by smaller file first. With merging disabled, every file of the same movie appears as its own poster.
- Collections can appear at the top of movie or TV lists. Custom collections respect their switches and can open the first member directly.
- Detail pages and library playback now share the same version priority; choosing a version manually plays that file.
- Re-scraping removes only migrated files and keeps files or collection members that were not covered by the new results.

## AI scraping and metadata

- Moved to the v2 media-scrape contract with stable batch IDs and index validation, rejecting missing, duplicate, or misaligned results. Retryable failures are retried up to three times with 10 files per batch, a 60-second client timeout, and a 0.70 confidence threshold.
- AI results can now return multiple episodes and season zero (specials). Episode results are merged in batches and no longer depend on a server-provided TMDB ID.
- Improved year detection for filenames separated by spaces or dots while preserving numeric titles such as 1917, 2012, and The Wandering Earth 2.
- TMDB request timeouts now cover response body reads, and HTTP 408 is retried, preventing stalls on incomplete responses.
- Audio extensions are recognized before provider-supplied video categories, fixing icons and classification for mislabeled cloud audio files.

## Playback and media library

- Music playback now uses embedded MPV in audio-only mode with authenticated source headers, equalizer, panner, and speed effects, plus automatic next-track handling. Progress, volume, mute, and seek state stay in sync.
- Video playback can automatically download subtitles only when embedded, same-folder, and previously downloaded subtitles are all absent. Failures never interrupt playback.
- Auto-play next in General settings and the in-player setting now stay in sync.
- Fixed PDF rendering races during rapid page changes or zooming, bounded raster memory, and serialized rendering. The image viewer disables transitions to improve gesture response.
- Fixed empty child folders when recursively downloading from a drive root and adjusted episode heading layout on detail pages.
- Ratings, logos, watch indicators, and daily picks in media-server and local libraries now follow the General display settings.

## File sources and interface improvements

- Unified empty states on Home and Files; sort buttons now show the current field and direction.
- Corrected embedded MPV option encoding to keep multiple authentication headers together.

- Fixed folder favorites from the file browser context menu, including Aliyun backup drives: setup now prompts for a name, starts scraping, and shows the saved cards. Whole-drive favorites and stars share the same flow.

- File source setup now uses a two-pane layout: enter a source name before connecting a cloud drive. Authorization stays in the right pane without opening the legacy drive sign-in dialog.
- WebDAV and AList are grouped under network shares. Emby, Jellyfin, Plex, and local folders use consistent inline setup forms.
- Added custom source names and improved source browsing, folder favorites, and media-server favorite shortcuts.
- Unified dialog, dropdown, and overlay backgrounds in light and dark themes; refined settings and membership screens and clarified Aliyun backup/resource drive labels.
- Unified application update notices with download status and release notes.
