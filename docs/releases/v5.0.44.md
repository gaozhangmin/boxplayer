# BoxPlayer 5.0.44

## 简体中文

### 音乐播放器与歌词
- 视觉预设中增加“清爽播放界面”，使用封面与歌曲信息展示；粒子界面保留原有场景，本次没有新增粒子场景。
- 新增流光歌词及文字、光效、背景配色，桌面歌词同步支持普通与流光模式。
- 优化普通歌词的当前行与未播放行层次；手动浏览歌词时暂停自动居中，随后恢复跟随。
- 改进桌面歌词窗口拖动、锁定和外观同步，修复窗口首次打开时歌词未同步及打包后页面加载问题。
- 播放控制台和队列显示歌曲下载进度、完成、暂停与失败状态。

### 音乐库与文件来源
- 改进本地音乐的标签、封面和歌词读取，以及本地歌曲的播放地址处理。
- 改进歌曲信息补全与失败封面处理，减少重复处理和无效请求。
- 优化网盘容量刷新及界面更新，修复天翼家庭目录层级异常。
- 媒体服务器详情补充可用的文件路径，改进 STRM 内容信息展示。

## 繁體中文

### 音樂播放器與歌詞
- 視覺預設加入「清爽播放介面」，以封面與歌曲資訊呈現；粒子介面保留既有場景，本次沒有新增粒子場景。
- 新增流光歌詞及文字、光效、背景配色，桌面歌詞同步支援普通與流光模式。
- 改善普通歌詞目前行與未播放行的層次；手動瀏覽歌詞時暫停自動置中，之後恢復跟隨。
- 改善桌面歌詞視窗拖曳、鎖定與外觀同步，修復首次開啟時歌詞未同步及封裝後頁面載入問題。
- 播放控制台與佇列顯示歌曲下載進度、完成、暫停及失敗狀態。

### 音樂庫與檔案來源
- 改善本機音樂標籤、封面、歌詞讀取及本機歌曲播放位址處理。
- 改善歌曲資訊補全與失效封面處理，減少重複處理和無效請求。
- 改善網路磁碟容量重新整理與畫面更新，修復天翼家庭目錄層級異常。
- 媒體伺服器詳情補充可用檔案路徑，改善 STRM 內容資訊顯示。

## English

### Music player and lyrics
- Add a Clean Playback Interface alongside the existing visual presets, presenting album artwork and track information. Existing particle scenes are retained; this release adds no new particle scenes.
- Add flowing lyrics with separate text, light and background colors, including standard and flowing modes for desktop lyrics.
- Refine active and inactive lyric lines. Manual lyric browsing temporarily pauses automatic centering before tracking resumes.
- Improve desktop lyric dragging, locking and appearance synchronization. Fix missing lyrics when first opening the window and loading the packaged lyric page.
- Show download progress and completed, paused and failed states in the playback console and queues.

### Music library and file sources
- Improve local audio tags, artwork, lyrics and playback URL handling.
- Improve metadata enrichment and failed artwork handling to reduce repeated work and unnecessary requests.
- Improve cloud storage capacity refresh and visible account updates; fix Tianyi family directory hierarchy handling.
- Show available file paths in media server details, including STRM entries.
