## 简体中文

### 新增
- 新增 SMB、NFS、FTP 网络共享文件来源；文件来源支持 SMB、NFS、WebDAV、Alist、FTP，可浏览、播放和扫描入库。
- 音乐库支持置顶专辑、歌单和歌曲，新增歌曲下载和更多操作菜单。

### 改进
- 拖动进度条时的预览图加载更快，加载中显示指示图标。
- 本地视频读取时长、分辨率与 HDR 信息，无需先解码。
- WebDAV 连接与播放兼容性改进。

### 修复
- 修复进度条预览图因请求头无法传递而不显示的问题。
- 重新刮削后的歌曲不再重复出现在“最近添加”中。

## 繁體中文

### 新增
- 新增 SMB、NFS、FTP 網路共享檔案來源；檔案來源支援 SMB、NFS、WebDAV、Alist、FTP，可瀏覽、播放與掃描入庫。
- 音樂庫支援置頂專輯、歌單與歌曲，新增歌曲下載與更多操作選單。

### 改進
- 拖動進度條時的預覽圖載入更快，載入中顯示指示圖示。
- 本機影片讀取時長、解析度與 HDR 資訊，無需先解碼。
- WebDAV 連線與播放相容性改進。

### 修復
- 修復進度條預覽圖因請求標頭無法傳遞而不顯示的問題。
- 重新刮削後的歌曲不再重複出現在「最近新增」中。

## English

### New
- SMB, NFS and FTP network share sources. File sources now cover SMB, NFS, WebDAV, Alist and FTP for browsing, playback and library scanning.
- Pin albums, playlists and songs in the music library, plus song downloads and a More actions menu.

### Improved
- Seek bar preview thumbnails load faster and show a loading indicator.
- Local videos read duration, resolution and HDR information from the container without decoding.
- Better WebDAV connection and playback compatibility.

### Fixed
- Seek bar previews failed to appear because request headers could not be passed.
- Rescanned songs no longer reappear in Recently Added.
