# BoxPlayer v5.0.34

## 重点更新：内置 MPV 成为默认播放器

桌面版默认使用内置 MPV，仍可选择内置网页播放器或自定义播放软件。支持 macOS arm64/x64、Windows x64 和 Linux x64/arm64；Windows ARM64 暂不支持，也不提供对应安装包。

内置 MPV 提供播放/暂停、进度跳转、倍速、音量、章节、播放列表、画面比例、视频内置音轨与字幕切换，以及外挂字幕加载。网盘与 Emby 播放保留来源要求的 Authorization、Cookie、User-Agent、Referer、Origin 等请求头；需鉴权的媒体与字幕使用账号感知的本地代理。

## 稳定性与测试

- 修复内置 MPV 关闭、重新打开或结束播放时可能导致 Electron 闪退的问题。
- 改进 Emby 直连播放、请求头处理与播放失败诊断。
- 修复真实播放测试中 Electron 未正常退出造成的 CI 超时。
- 在 Windows x64、Linux x64/arm64、macOS arm64/x64 验证真实网盘和 Emby 的 MPV 播放。Windows 不再运行单独的网盘搜索、上传、下载与文件操作测试。115、Box 和 189 暂不纳入真实账号播放门禁。
- 修复 Google Drive 账号切换按钮无响应、网页播放器字幕菜单重复层级，并改进夸克鉴权下载与 115/Box 刷新令牌处理。

## English

### Embedded MPV is now the default player

The desktop app now defaults to embedded MPV while retaining the built-in web player and external-player options. Supported platforms are macOS arm64/x64, Windows x64, and Linux x64/arm64. Windows ARM64 is not supported and no installer is provided.

Embedded MPV supports playback controls, seeking, speed, volume, chapters, playlists, aspect controls, audio-track and subtitle switching, and external subtitles. Cloud-drive and Emby playback preserve required authorization, cookies, User-Agent, Referer, and Origin headers; an account-aware local proxy handles authenticated media and subtitles.

### Stability and validation

- Fixed an intermittent Electron crash when closing, reopening, or finishing MPV playback.
- Improved direct Emby playback, authentication-header handling, and failure diagnostics.
- Fixed CI teardown timeouts caused by Electron processes that did not exit cleanly.
- Real cloud-drive and Emby MPV playback is validated on all supported desktop platforms. Windows no longer runs separate search, upload, download, or file-operation API tests. 115, Box, and Tianyi 189 are excluded from the real-account playback gate for now.
- Also fixes Google Drive account switching and the duplicate web-player subtitle-menu layer, with Quark authenticated-download and 115/Box token-refresh improvements.
