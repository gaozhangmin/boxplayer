# BoxPlayer 5.0.50

## 简体中文

### 新增
- **支持本地与 NAS `.nfo` 及本地海报读取**：扫描本地文件夹、SMB、NFS、FTP、WebDAV 与 AList 时，自动读取同目录 `.nfo`（支持 `movie.nfo` / `<片名>.nfo` / `tvshow.nfo` 及季度子目录继承 / 单集 `.nfo`）与本地海报、背景图及单集缩略图；当 TMDB 未收录或离线且 `.nfo` 包含片名时，直接回退使用本地 `.nfo` 元数据与缓存图片入库。
- **光鸭云盘大文件播放回退**：非会员触发网页端文件大小限制（`code 254`）时，自动回退获取 VOD 流媒体直链播放。
- **详情页网盘来源标签补全**：媒体详情页新增光鸭云盘、Google Drive、中国移动云盘、天翼云盘及 SMB / NFS / FTP 等来源标签显示。
- **内容指纹字段补齐**：Google Drive 与 WebDAV 目录项统一补充 `content_hash_name: 'md5'`，对齐跨端指纹刮削识别。

### 优化
- **TMDB 与音乐元数据扫描加速**：扫描阶段启用剧集与分级查询并发去重缓存，优化 AI 刮削与音乐元数据/封面富化处理性能。
- 网页播放器默认提示文案同步更新为清晰指引（「设置 → 播放」）。

### 修复
- **统一「未观看」聚合口径**：从「未观看」视图剔除未匹配项目，并在按合集折叠电影前先按成员电影过滤已观看与正在播放记录，与「所有电影」口径保持一致。
- **媒体服务器分类恢复**：恢复 Emby 与 Jellyfin 媒体服务器「播放列表（Playlists）」与「合集（BoxSets）」分类在首页视图、分页浏览及搜索中的显示与进入浏览。
- **网页播放器回退修复**：网页播放器以原画质播放网盘视频失败时，若存在转码 HLS 流则自动回退播放一次，修复切清晰度异常与错误状态滞留。
- **115 登录二维码修复**：115 网盘扫码登录二维码改为本地生成渲染与布局裁剪优化，避免二维码不显示。

## 繁體中文

### 新增
- **支援本機與 NAS `.nfo` 及本機海報讀取**：掃描本機資料夾、SMB、NFS、FTP、WebDAV 與 AList 時，自動讀取同目錄 `.nfo`（支援 `movie.nfo` / `<片名>.nfo` / `tvshow.nfo` 及季別子目錄繼承 / 單集 `.nfo`）與本機海報、背景圖及單集縮圖；當 TMDB 未收錄或離線且 `.nfo` 包含片名時，直接回退使用本機 `.nfo` 中繼資料與快取圖片入庫。
- **光鴨雲盤大檔案播放回退**：非會員觸發網頁端檔案大小限制（`code 254`）時，自動回退取得 VOD 串流直連播放。
- **詳情頁網路磁碟來源標籤補全**：媒體詳情頁新增光鴨雲盤、Google Drive、中國移動雲盤、天翼雲盤及 SMB / NFS / FTP 等來源標籤顯示。
- **內容指紋欄位補齊**：Google Drive 與 WebDAV 目錄項目統一補充 `content_hash_name: 'md5'`，對齊跨端指紋刮削識別。

### 優化
- **TMDB 與音樂中繼資料掃描加速**：掃描階段啟用劇集與分級查詢並行去重快取，優化 AI 刮削與音樂中繼資料／封面充實效能。
- 網頁播放器預設提示文案同步調整為清晰指引（「設定 → 播放」）。

### 修復
- **統一「未觀看」聚合口徑**：從「未觀看」檢視剔除未比對項目，並在依合集折疊電影前先依成員電影篩選已觀看與正在播放記錄，與「所有電影」口徑保持一致。
- **媒體伺服器分類恢復**：恢復 Emby 與 Jellyfin 媒體伺服器「播放列表（Playlists）」與「合集（BoxSets）」分類在首頁檢視、分頁瀏覽及搜尋中的顯示與進入瀏覽。
- **網頁播放器回退修復**：網頁播放器以原畫質播放網路磁碟影片失敗時，若存在轉碼 HLS 串流則自動回退播放一次，修正畫質切換異常與狀態殘留。
- **115 登入 QR Code 修復**：115 網路磁碟掃碼登入 QR Code 改為本機產生渲染與版面裁切最佳化，避免 QR Code 無法顯示。

## English

### New
- **Local & NAS `.nfo` and Artwork Sidecars**: Automatically read sibling `.nfo` metadata (`movie.nfo`, `<title>.nfo`, `tvshow.nfo` with Season folder inheritance, and episode `.nfo`) plus local posters, backdrops, and episode thumbs across local folders, SMB, NFS, FTP, WebDAV, and AList, falling back cleanly to local NFO metadata and cached artwork when TMDB misses or offline.
- **Guangya Non-VIP VOD Fallback**: Automatically fall back to VOD streaming URLs when non-VIP web download size limits (`code 254`) are hit on Guangya Drive.
- **Complete Cloud Source Labels**: Display source labels for Guangya, Google Drive, China Mobile Cloud, Tianyi Cloud, SMB, NFS, and FTP on media detail views.
- **MD5 Fingerprint Parity**: Populate `content_hash_name: 'md5'` for Google Drive and WebDAV items to align cross-platform fingerprint scraping.

### Improvements
- **Faster TMDB & Music Metadata Scanning**: Deduplicate and cache concurrent TV show and certification lookups during scans, and streamline AI scraping and music enrichment.
- Refine the Playback Settings default-player hint clarity.

### Fixes
- **Aligned "Unwatched" Aggregation**: Exclude unmatched items from Unwatched views and filter watched/in-progress movies at the member level before collapsing collections so counts match All Movies.
- **Emby & Jellyfin Collections Restored**: Restore Emby and Jellyfin Playlists and BoxSets collections in media server views, paged browsing, and search.
- **Web Player Origin-to-HLS Fallback**: Automatically fall back once from a failed Origin stream to available transcoded HLS playback in the built-in web player without stale reconnect state.
- **115 Sign-In QR Rendering**: Generate and size the 115 Drive login QR code locally without clipping so it displays reliably.
