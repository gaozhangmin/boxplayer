# BoxPlayer v5.0.30

## 变更摘要

- 优化书籍阅读器与 PDF 阅读器的 BoxPlayer AI 对话体验：统一对话视觉、排版与输入提示；PDF 侧栏支持鼠标拖拽调整宽度，PDF 工具栏的 AI 按钮改为直接打开对话框。
- 新增“AI 刮削”设置。启用后，常规刮削完成才会把未匹配媒体交给 AI 处理；移除独立的 AI 刮削菜单，流程与 iOS 保持一致。
- 修复内置 AI 上游模型或流式桥接失败被误提示为“本月内置 AI 额度已用完”的问题。
- 改善文档 AI 的失败反馈和本地索引模块恢复提示。
- 修复天翼云盘会话失效后的自动刷新与重试，避免 `InvalidSessionKey` 直接中断文件请求。
- 移除不适用于当前能力范围的文件与目录菜单项。

## English

- Refined the BoxPlayer AI chat experience in the book and PDF readers with unified visual treatment, typography, and composer guidance. The PDF sidebar is mouse-resizable, and its AI toolbar button now opens chat directly.
- Added an **AI scraping** setting. When enabled, unmatched media is handed to AI only after normal scraping finishes; the separate AI scraping menu has been removed to match iOS.
- Fixed upstream-model and streaming-bridge failures being incorrectly reported as the monthly built-in AI quota being exhausted.
- Improved document-AI error feedback and local indexing recovery guidance.
- Fixed Tianyi Cloud session refresh and retry handling for `InvalidSessionKey` responses.
- Removed file and directory menu items outside the currently supported capability set.
