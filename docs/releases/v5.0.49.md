# BoxPlayer 5.0.49

## 简体中文

- 恢复 Emby 与 Jellyfin 媒体服务器「播放列表（Playlists）」与「合集（BoxSets）」分类在首页视图、分页浏览及搜索中的显示与进入浏览。
- 网页播放器以原画质播放网盘视频失败时，若存在转码 HLS 流则自动回退播放一次；同步修正「设置 → 播放」默认播放器提示文案。
- 修复 115 网盘扫码登录二维码改为本地生成渲染与布局裁剪，避免二维码不显示。

## 繁體中文

- 恢復 Emby 與 Jellyfin 媒體伺服器「播放列表（Playlists）」與「合集（BoxSets）」分類在首頁檢視、分頁瀏覽及搜尋中的顯示與進入瀏覽。
- 網頁播放器以原畫質播放網路磁碟影片失敗時，若存在轉碼 HLS 串流則自動回退播放一次；同步修正「設定 → 播放」預設播放器提示文案。
- 修復 115 網路磁碟掃碼登入 QR Code 改為本機產生渲染與版面裁切，避免 QR Code 無法顯示。

## English

- Restore Emby and Jellyfin Playlists and BoxSets collections in media server views, paged browsing, and search.
- Automatically fall back once from a failed Origin stream to available transcoded HLS playback in the built-in web player, and align the Playback Settings default-player hint.
- Render the 115 Drive sign-in QR code locally without container clipping so it displays reliably.
