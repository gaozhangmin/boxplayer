# BoxPlayer v5.0.40

## 简体中文

### 新增
- 内置 MPV 播放器新增进度缩略图预览；悬停或拖动进度条可查看对应画面，网页播放器共用预览能力。
- 新增与 Apple macOS 一致的片头片尾设置弹窗：总开关、独立开关、使用当前位置及每次 1 秒调整；片尾按距离结束的时长设置，关闭开关保留已设时长。
- 内置 MPV 倍速菜单支持 0.5×–10×，每档 0.25×，可滚动选择；同步放宽原生播放内核的倍速上限。

### 改进
- 内置 MPV 控件对齐 macOS：左侧音量弹层、中间上一项/后退/播放暂停/快进/下一项、右侧设置/画中画/全屏；进度条显示当前时间、剩余时间，并区分已播放、已缓冲与未缓冲部分。
- 设置菜单集中字幕、弹幕、速度及画面比例；倍速与比例使用纵向选择菜单，字幕、弹幕入口直达相应 tab，设置 tab 栏始终可见。
- 完善主副字幕的延迟、位置、缩放、不透明度、字体、颜色、描边和阴影设置，以及文本样式与原生字幕布局的配合。
- 统一全局与播放中的弹幕偏好，增加搜索历史、年份匹配、短视频跳过、字体、简繁转换、固定弹幕转滚动、延迟和描边等设置。
- 优化 MPV 进度缓冲展示；调整媒体库横幅、首页列表分隔与导航，改善音乐封面和继续观看展示。
- 启动密码设置采用统一输入框、独立字段标签和按钮布局；确认密码不一致或不是四位数字时禁用保存。

### 修复
- 夸克下载接口遇到临时网关错误时自动重试，非 JSON 错误响应不再中断播放地址解析。
- 修复安装包遗漏 aria2-lib、@motrix/nat-api 及其运行依赖，导致 Linux/AUR 下载引擎初始化失败的问题（#535），并增加桌面安装包依赖完整性检查。
- 修复全屏启动锁与 Touch ID 验证相关问题，改善从详情页继续播放时的进度选择。
- 保留 MPV 加载失败时的底层 HTTP/TLS/解码错误，过滤日志中的媒体链接与敏感请求信息，便于定位播放问题。
- 合入 5.0.39 发布分支修正，保留搜索增量展示、取消过期请求及服务器注册表初始化。

## 繁體中文

### 新增
- 內建 MPV 播放器新增進度縮圖預覽；游標停留或拖曳進度列可查看對應畫面，網頁播放器共用預覽能力。
- 新增與 Apple macOS 一致的片頭片尾設定彈窗：總開關、獨立開關、使用目前位置及每次 1 秒調整；片尾依距離結束的時長設定，關閉開關保留已設時長。
- 內建 MPV 倍速選單支援 0.5×–10×，每級 0.25×，可捲動選擇；同步提高原生播放核心的倍速上限。

### 改進
- 內建 MPV 控制項對齊 macOS：左側音量彈出面板、中間上一項/倒退/播放暫停/快轉/下一項、右側設定/子母畫面/全螢幕；進度列顯示目前時間、剩餘時間，並區分已播放、已緩衝與未緩衝部分。
- 設定選單集中字幕、彈幕、速度及畫面比例；倍速與比例採用直向選擇選單，字幕、彈幕入口直達對應分頁，設定分頁列持續顯示。
- 完善主副字幕的延遲、位置、縮放、不透明度、字型、顏色、外框和陰影設定，以及文字樣式與原生字幕配置的配合。
- 統一全域與播放中的彈幕偏好，增加搜尋歷史、年份比對、略過短片、字型、簡繁轉換、固定彈幕轉捲動、延遲及外框等設定。
- 改善 MPV 進度緩衝顯示；調整媒體庫橫幅、首頁列表分隔及導覽，改善音樂封面與繼續觀看顯示。
- 啟動密碼設定採用統一輸入框、獨立欄位標籤及按鈕配置；確認密碼不符或不是四位數字時停用儲存。

### 修正
- 夸克下載介面遇到暫時閘道錯誤時自動重試，非 JSON 錯誤回應不再中斷播放位址解析。
- 修正安裝包遺漏 aria2-lib、@motrix/nat-api 及其執行依賴，造成 Linux/AUR 下載引擎初始化失敗的問題（#535），並新增桌面安裝包依賴完整性檢查。
- 修正全螢幕啟動鎖與 Touch ID 驗證相關問題，改善從詳情頁繼續播放時的進度選擇。
- 保留 MPV 載入失敗時的底層 HTTP/TLS/解碼錯誤，過濾紀錄中的媒體連結與敏感請求資訊，便於定位播放問題。
- 合入 5.0.39 發布分支修正，保留搜尋結果逐步顯示、取消過期請求及伺服器登錄資料初始化。

## English

### Added
- Timeline thumbnail previews for the embedded MPV player. Hover or drag the timeline to preview a frame; the web player shares the same preview support.
- An Apple macOS-style intro/outro dialog with a master switch, independent switches, current-position markers and one-second adjustments. Outro length is measured from the end, and disabling a switch preserves its duration.
- A scrollable embedded MPV speed menu from 0.5× to 10× in 0.25× increments, with the native playback limit raised accordingly.

### Improvements
- Align embedded MPV controls with macOS: a volume popover on the left, centered previous/rewind/play-pause/forward/next controls, and settings/picture-in-picture/fullscreen on the right. The timeline shows elapsed and remaining time and distinguishes played, buffered and unbuffered portions.
- Group subtitles, danmaku, speed and aspect ratio in the settings menu. Speed and aspect ratio use vertical selection menus; subtitle and danmaku entries open their respective tabs, and the settings tab bar stays visible.
- Refine primary and secondary subtitle delay, placement, scale, opacity, fonts, colors, outlines and shadows, including coordination between text styling and native subtitle layout.
- Unify global and in-player danmaku preferences, including search history, year matching, skipping short videos, fonts, Chinese script conversion, converting fixed comments to scrolling comments, delay and outlines.
- Improve MPV buffer display. Refine library banners, home row separators and navigation, music artwork and continue-watching presentation.
- Use consistent startup password fields, separate labels and button layout. Saving is disabled for mismatched confirmation or a PIN that is not four digits.

### Fixes
- Retry temporary Quark download gateway failures and handle non-JSON errors without aborting playback URL resolution.
- Include aria2-lib, @motrix/nat-api and their runtime dependencies in desktop packages, fixing Linux/AUR download engine initialization failures (#535), and add packaged dependency checks.
- Fix fullscreen startup-lock and Touch ID verification issues, and improve resume-position selection when playing from a details page.
- Preserve underlying HTTP/TLS/decoder errors when MPV fails to load media, while redacting media URLs and sensitive request information from diagnostics.
- Merge the 5.0.39 release fixes while preserving incremental search results, stale request cancellation and media server registry initialization.
