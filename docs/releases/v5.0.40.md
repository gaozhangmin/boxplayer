# BoxPlayer v5.0.40

## 简体中文

### 改进
- 启动密码设置使用统一的密码输入框、独立字段标签和按钮布局；确认密码不一致或不是四位数字时禁用保存。
- MPV 播放进度条区分已播放、已缓冲与未缓冲部分。

### 修复
- 修复安装包遗漏 aria2-lib、@motrix/nat-api 及其运行依赖，导致 Linux/AUR 下载引擎初始化失败的问题（#535）。新增各桌面安装包的依赖完整性检查。
- 合入 5.0.39 发布分支修正，保留搜索增量展示、取消过期请求及服务器注册表初始化。

## 繁體中文

### 改進
- 啟動密碼設定採用統一的密碼輸入框、獨立欄位標籤及按鈕配置；確認密碼不符或不是四位數字時停用儲存。
- MPV 播放進度列區分已播放、已緩衝與未緩衝部分。

### 修正
- 修正安裝包遺漏 aria2-lib、@motrix/nat-api 及其執行依賴，造成 Linux/AUR 下載引擎初始化失敗的問題（#535）。新增桌面安裝包依賴完整性檢查。
- 合入 5.0.39 發布分支修正，保留搜尋結果逐步顯示、取消過期請求及伺服器登錄資料初始化。

## English

### Improvements
- Startup password settings now use themed password fields, separate labels and consistent buttons. Saving is disabled for mismatched confirmation or a PIN that is not four digits.
- The MPV timeline distinguishes played, buffered and unbuffered portions.

### Fixes
- Include aria2-lib, @motrix/nat-api and their runtime dependencies in desktop packages, fixing Linux/AUR download engine initialization failures (#535). Add packaged dependency checks for desktop builds.
- Merge the 5.0.39 release fixes while preserving incremental search results, stale request cancellation and media server registry initialization.
