# BoxPlayer v5.0.33

## 重点更新：内置 MPV 成为默认播放器

桌面版默认使用内置 MPV，仍可在设置中选择内置网页播放器或自定义播放软件。内置 MPV 支持 macOS arm64/x64、Windows x64 和 Linux x64/arm64，提供播放控制、进度跳转、倍速、音量、章节、播放列表、画面比例，以及视频内置音轨和字幕切换、外挂字幕加载。

网盘及 Emby 播放会保留各来源要求的 Authorization、Cookie、User-Agent、Referer、Origin 等请求头，并在需要时通过账号感知的本地代理加载媒体和字幕。原画与其他可用清晰度切换也会保留鉴权信息。

## 本版稳定性修复

- 修复内置 MPV 关闭、重新打开或结束播放时可能导致 Electron 闪退的问题。
- 改进 Emby 直连播放及所需请求头的处理，并加强播放失败诊断。
- 修复真实播放测试中 Electron 退出后残留进程导致的 CI 超时。
- 发布门禁在各桌面平台验证真实网盘与 Emby 的 MPV 播放；Windows 不再运行单独的网盘搜索、上传、下载及文件操作测试。115、Box 和 189 暂不纳入真实账号播放门禁。

## 其他修复

- 修复 Google Drive 账号切换按钮无响应。
- 改进夸克网盘的鉴权下载，以及 115、Box 的刷新令牌处理。
- 改进部分网盘的上传与错误提示，并修复网页播放器重复的字幕菜单层级。

## English

### Embedded MPV is now the default player

The desktop app now defaults to embedded MPV while retaining the built-in web player and custom external players. It supports macOS arm64/x64, Windows x64, and Linux x64/arm64, with playback controls, seeking, speed, volume, chapters, playlists, aspect controls, audio-track and subtitle switching, and external subtitles.

Cloud-drive and Emby playback preserve provider-required authorization, cookies, User-Agent, Referer, and Origin headers. Account-aware local proxying handles authenticated media and subtitles when needed.

### Stability and release validation

- Fixed an intermittent Electron crash when closing, reopening, or finishing MPV playback.
- Improved direct Emby playback, request-header handling, and playback diagnostics.
- Fixed test teardown timeouts caused by Electron processes that did not exit cleanly.
- Real cloud-drive and Emby MPV playback is validated on supported desktop platforms. Windows no longer runs separate search, upload, download, or file-operation API tests. 115, Box, and Tianyi 189 are excluded from the real-account playback gate for now.
- Also includes Google Drive account-switch, Quark authenticated-download, 115/Box token-refresh, and duplicate web-player subtitle-menu fixes.
