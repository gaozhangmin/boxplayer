# BoxPlayer v5.0.29

## 变更摘要

- 统一 Pro 购买入口为“官网登录并购买”：App 会携带当前会话进入官网，购买完成后通过 `boxplayer-auth://callback` 返回并恢复登录状态，避免重复输入邮箱验证码。
- 增加官网登录回调处理，支持授权码交换和会话恢复，并在本地安全保存 App 会话令牌。
- 修复邮箱登录退出后仍停留在验证码输入状态的问题；退出后可以重新从邮箱登录流程开始。
- 为官网购买链接、授权回调和邮箱登录状态重置增加单元测试与 Playwright 回归覆盖。
- 调整 CI 触发规则，推送 `main` 不再启动 MPV 集成工作流，避免普通代码推送消耗发布资源。

## English

- Unified the Pro purchase entry as “Sign in on website to purchase”. The app carries the current session to the website, restores the authenticated session through `boxplayer-auth://callback`, and avoids asking for the email verification code twice.
- Added website OAuth callback handling with authorization-code exchange and session restoration, with the app session token stored locally.
- Fixed the email login form remaining in verification-code mode after logout; users can start a new email login flow normally.
- Added unit and Playwright regression coverage for the purchase URL, OAuth callback, and email-login reset flow.
- Updated CI triggers so ordinary pushes to `main` no longer start the MPV integration workflow.
