# BoxPlayer 5.0.45

## 简体中文

- 媒体服务器连接超时、断网或服务异常时保留已保存的登录状态，仅明确的未授权响应才标记凭据失效。
- 移除媒体服务器浏览页中不适用的文件扫描进度和来源路径提示，保留网盘与本地来源原有扫描界面。

## 繁體中文

- 媒體伺服器連線逾時、斷網或服務異常時保留已儲存的登入狀態，僅明確的未授權回應才標記憑證失效。
- 移除媒體伺服器瀏覽頁中不適用的檔案掃描進度及來源路徑提示，保留網路磁碟及本機來源原有掃描介面。

## English

- Keep saved media-server sign-in state during timeouts, offline connections and server errors; invalidate credentials only on explicit unauthorized responses.
- Remove inapplicable file-scan progress and source-path hints from media-server browsing, preserving scan controls for cloud and local sources.
