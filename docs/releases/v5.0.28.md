# BoxPlayer v5.0.28

## 变更摘要

- 修复 Windows 自动更新下载完成后重复下载同一版本的问题，持久化待安装版本并在版本更新后清理状态。
- 增加天翼云盘与 139 云盘的分片上传实现，并接入普通文件上传能力。
- 修正天翼云盘上传请求的参数加密、签名和上传域名请求头。
- 增加天翼云盘与 139 云盘真实账号上传回归用例及协议单元测试。

## English

- Fixed Windows auto-update loops by persisting the downloaded version, preventing duplicate downloads, and clearing the pending state after installation.
- Added multipart file uploads for Tianyi Cloud (189) and 139 Cloud and wired them into normal file upload flows.
- Corrected Tianyi upload parameter encryption, request signing, and upload-host request headers.
- Added real-account upload regression coverage and protocol unit tests for both providers.
